HONEST DE-SIGN OR NOTHING

Nine clauses against the soft lie of frictionless UI. If the interface has weight, show the weight. If the rule has an exception, print the exception in red. This is not a moodboard. This is a contract.

*
* Terms apply to everyone, including us
01

Show the seams

A border is not a failure of taste. It is a map of responsibility. If a control can be pressed, it must look like it can be pressed. Hide nothing that the user will later be blamed for missing.

02

Weight is information

Heavy type for irreversible acts. Thin type for asides. If delete and save share a weight, the product is lying about consequence.

03

Four colours. No more.

Paper, ink, acid, signal. Extra hues are usually a substitute for a missing hierarchy. If you need a fifth colour, you need a better sentence.

04

Type that shouts and type that files

Display is condensed, black, and slightly too large. Body is monospace because it does not pretend to be literature. Mixing them is the whole point.

05

No easing of blame

Transitions are steps, not sighs. A button slams. A form rejects. Smoothness is often how products delay the news.

06

Write the rule

Labels name the action. Errors name the cause. Empty states name the next move. Decorative copy is a leak.

07

Forms are contracts

Validate in the open. Duplicate names are a conflict, not a vibe. The status line is part of the interface, not a toast that evaporates.

08

Keyboard is not extra

If a card inverts on hover it inverts on Enter. Focus is a 4px fact. Touch users pin the state because fingers are not cursors.

09

Approved for public disagreement

This manifesto is not a brand. Sign it if you will argue with it in public. Honest design or nothing — including us.
