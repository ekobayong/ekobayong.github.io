Section 01

Specimen sheet, from poster to footnote

Every size on a single page. The pangram never changes; only the scale does, from 144 points down to 14, so you can watch the counters close and the rhythm tighten as the type shrinks.

Section 02

Type tester, tune the metal while it's hot

Set your own line and push it around. Size, tracking and leading all update live; the info string in the corner records the setting like a compositor's ticket.
