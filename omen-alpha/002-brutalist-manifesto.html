The Nine Clauses

Pin any clause with Enter or Space

01

Weight is information

A heavy border says "this matters". A hard shadow says "this sits above that". Interfaces that erase their own weight ask you to trust a rumour. We keep the weight visible so the hierarchy is read, not guessed.

02

Show the seams

A polished surface hides how it was made. A honest one leaves the joint lines out in the open. When you can see the construction, you can question it — and interfaces that can be questioned can be fixed.

03

No fake data

Every number on screen is a claim. If the spinner has no spinner behind it, delete the spinner. Skeleton screens lie about progress; progress bars that wander lie about time. Show the real state or show nothing.

04

Stepped, not sneaky

Motion should carry meaning in its timing. Smooth 300ms eases hide cause and effect. We prefer transitions you can count — steps you can feel — so the interface behaves like a machine, not a magician.

05

The keyboard is first class

If a control cannot be reached with a Tab key, it is decoration. Focus rings are not blemishes to be tidied away; they are the interface speaking to its most determined users. Every card on this page is focusable. Check us.

06

Four colours are enough

Paper, ink, acid, red. A strict palette forces meaning into every choice: highlight, alarm, action, rest. When everything can be any colour, nothing means anything. Constraint is the cheapest design tool there is.

07

Errors are copywriting

An error message is the moment your product is most honest, or most evasive. "Something went wrong" is a shrug. Name the failure, name the cause, name the way out — in plain monospace, at full contrast, in the user's language.

08

Defaults are decisions

The default state is what most people will live with forever, so it is never neutral. Every default we ship is an argument we are willing to defend in public. Choose defaults you can stamp your name under.

09

The ninth clause binds the authors

These rules apply to this page first. The borders are really 4px, the palette is really four colours, the button really slams. If you find a lie here, it becomes a design bug — file it, loudly, and we will fix it in daylight.
