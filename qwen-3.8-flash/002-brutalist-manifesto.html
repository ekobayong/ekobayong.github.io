Honest DE-SIGN OR NOTHING

Nine clauses on what an interface owes the human on the other side of the glass. Written in the same typeface we ship our errors in, on a page that asks for nothing and loads nothing but itself. Read it against the wall of soft shadows you're currently pretending is design.

The Nine Clauses

Hover to invert · Enter / Space to pin

Pinned 01

The interface owes the user the truth

Every spinner, skeleton and shimmer is a claim about what the system is doing. A loader that hides a request that failed forty seconds ago is a lie drawn at sixty frames per second. If the system is uncertain, show the uncertainty. If it failed, say it failed — and say what happens next.

Pinned 02

Show the seams

Load state, error state, empty state, offline state — design them with the same care as the demo shot. A page that only looks honest while the API answers is theatre with a status code attached.

Pinned 03

Weight is information

A button you must press should look pressable. A link you merely tap should not cast a shadow across three imaginary rooms of elevation. Affordance is meaning; decoration that breaks the page's own physics is a false affordance.

Pinned 04

Motion must mean something

Animation is grammar: it shows where a thing came from and where it went. A transition that exists to be noticed is noise with a curve. If you cannot finish the sentence "this moves so the user learns that…", delete it.

Pinned 05

Defaults are policy

Whatever is pre-checked, pre-agreed and pre-shared is your position — expressed at a scale no press release will reach. The opt-out nobody reads is still legislation. Write your defaults like someone's grandmother will have to live with them.

Pinned 06

Friction is a feature

Speed is not the only virtue. Deletion that cannot be undone deserves a second question. Make friction proportional to consequence — and never asymmetric: easy to enter, hard to leave is a trap, not a funnel.

Pinned 07

Delete more than you add

Every option shipped is an option someone must explain, translate, test, and live with forever. The strongest move in most product meetings is still the one that removes a screen. Complexity is not a feature you can market your way out of; a smaller honest interface beats a bigger clever one the way a straight answer beats a fluent one.

Pinned 08

Credit where it loads

If attention is the product, say so. Feeds that pretend to be chronological, "recommended" that means monetised, counts that inflate — each buys a little engagement with a lot of trust, and the exchange rate never improves.

Pinned 09

All nine clauses apply to us, including this one

We ship every one of these imperfections on a good week. The difference is the changelog: when we break a clause, we write it down in plain language, on the public record, with the word for what we got wrong being our own. No clause is exempt for its authors. That is the entire deal — honest design, or nothing with a mission statement.
